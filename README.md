# Farewell Fund

A small browser-based tracker for shared pools. Add a target, record each person's payment, and get a minimal list of transfers that settles all balances fairly.

## Run locally

Requires Node.js 18 or newer.

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000). Data is saved to the browser's local storage; no server-side database or account is required.

## Test

```bash
npm test
```
